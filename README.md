Guess the number that is randomly generated by the CPU. Many more features will be added in future updates so stay tuned.

## Built With

- [Expo](https://expo.dev) and [Expo Router](https://docs.expo.dev/router/introduction/) for the app shell and the file-based routes.
- [RootNative UI](https://rootnative.github.io/ui/) for the theme and all UI components. RootNative UI is a Material Design 3 component library for React Native.
  - `@rootnative/core` supplies the theme engine. The app creates its theme with `createMaterialTheme` and reads the colors with `useTheme`.
  - `@rootnative/components` supplies the UI components.
  - [`@rootnative/inertia`](https://rootnative.github.io/inertia/) supplies the animation primitives that the components use.
